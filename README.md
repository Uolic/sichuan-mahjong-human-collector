# 四川麻将真人出牌采集

这是一个手机优先的匿名出牌采集页面。参与者不需要打完整麻将，只需要根据当前手牌和桌面公开信息选择一张要打出的牌。每一轮随机抽取 20 题。

在线页面：https://uolic.github.io/sichuan-mahjong-human-collector/

## 牌桌界面

- 手机优先的四方牌桌、牌河和副露展示；
- 万字使用“汉字＋萬”，索子使用竹节图案，筒子使用彩色圆环阵列；
- 选牌上浮、出牌动画和触觉反馈；
- 支持定缺、向听、听牌与剩余牌墙提示；
- 可添加到手机主屏幕，作为轻量应用打开。

## 在线使用

GitHub Pages 部署后，直接打开仓库公开的 Pages 地址即可参与。

GitHub Pages 是纯静态托管，不能直接接收提交文件。答完一轮后，参与者需要点击“下载并分享结果”，再把 JSON 文件分享给项目负责人。需要自动汇总提交时，请使用项目内的手机采集服务或部署带数据库的服务端。

## 本地运行

此目录没有第三方依赖。可以用任意静态文件服务器启动：

```powershell
python -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。本地静态服务器与 GitHub Pages 行为相同，不会自动收取答案。

## 数据内容

页面只记录以下信息：

- 匿名随机编号和本次会话编号；
- 参与者自报的麻将经验等级；
- 题目标识、手牌状态、合法动作和桌面公开信息；
- 选择的牌或“跳过”；
- 每题响应时间和提交时间。

页面不收集姓名、手机号、微信号、精确位置或设备标识。不要将参与者的私密聊天、联系方式或其他个人信息写入提交结果。

## 题池

`tasks.json` 包含 800 道由规则引擎生成的真实局面选择题。页面每轮随机抽取 20 道。题池不应包含对手隐藏手牌。

重新生成题池、自动接收提交和审计数据需要完整训练项目中的生成器与服务端，不在此静态仓库中。

## 贡献

可以提交以下改进：

- 手机端交互和可访问性；
- 出牌题面的展示与规则正确性；
- 与现有数据格式兼容的接收端；
- 匿名数据去重、质量审计和反滥用；
- 成都血战到底规则下的新题池。

请勿提交真实姓名、联系方式、聊天记录、原始微信数据或未经授权的第三方棋谱。

## 部署

仓库包含 GitHub Pages 工作流。进入仓库的 **Settings → Pages**，将 **Source** 设置为 **GitHub Actions**。推送到 `main` 后，工作流会发布当前静态页面。
