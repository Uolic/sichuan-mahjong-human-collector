# 四川麻将真人出牌采集

这是一个手机优先的匿名出牌采集页面。连接项目内置接收服务时，参与者先亲自定缺，然后在同一局中连续出牌，AI 会摸打推进到下一手。纯静态 GitHub Pages 没有后端，会降级为同一牌局的连续关键手演示。

在线页面：https://uolic.github.io/sichuan-mahjong-human-collector/

## 牌桌界面

- 手机优先的四方牌桌、牌河和副露展示；
- 新手固定教学局、中等带提示局、高手无提示局三种模式；
- 新手局使用单步圈选导览、庄家先手弹幕和逐手助教提示；
- 新手固定局为可完成的清一色教学牌，并提供首轮碰/杠机会和必胜摸牌路线；
- 摸牌后会先高亮新牌，再由玩家选择弃牌；
- 碰、杠、胡带有牌桌中央印章特效，AI 行动卡直接提供“下一条”；
- AI 行动直接复用出牌建议区域，左右家牌河完整换行，横屏自动切换双栏；
- 实时显示本局得分、预计番数/分值和杠根，结算中的自己显示为“你”；
- 新手教学不进入正式采集，并可在结算页一键转到中等采集局；
- 正式服务支持亲自定缺和真实连续对局；
- 手牌自动理牌，手动顺序会跨摸牌保留；
- AI 行动慢速逐条回放，可碰可杠时给出选择按钮；
- 对手行动可手动逐条推进，并显示头像、动作章和具体牌面；
- 对家、左右家和自己的定缺直接标注在座位上；
- 静态页按同一牌局顺序展示，并明确提示选择不会改写已录制牌谱；
- 对家和“我”的牌河横向展开，左右家紧凑多列排列；
- 万字使用“汉字＋萬”，索子使用竹节图案，筒子使用彩色圆环阵列；
- 牌面解码失败会自动重试，最终失败时改为清晰的“数字 + 花色”兜底；
- 手牌支持鼠标或手指拖动换序，拖动时原位保留空槽；
- 首屏会预加载轻量题池，点击开始时显示“正在洗牌”反馈；
- 选牌上浮、出牌动画和触觉反馈；
- 支持定缺、向听、听牌与剩余牌墙提示；
- 可添加到手机主屏幕，作为轻量应用打开。

## 在线使用

GitHub Pages 部署后，直接打开仓库公开的 Pages 地址即可体验牌谱演示。

GitHub Pages 是纯静态托管，不能直接接收提交文件，也不能保存动态牌局状态。需要亲自定缺、连续打完整局并自动汇总时，请使用项目内的手机采集服务或部署带数据库的服务端。

正式采集只接收中等和高手局。每一局单独保存，结算页只显示本局结果与本局出牌数，不累计上一局或其他玩家。

## 本地运行

此目录没有第三方依赖。可以用任意静态文件服务器启动：

```powershell
python -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。本地静态服务器与 GitHub Pages 行为相同，不会自动收取答案。

## 数据内容

页面只记录以下信息：

- 匿名随机编号和本次会话编号；
- 参与者自报的麻将经验等级；
- 题目标识、手牌状态、合法动作和桌面公开信息；
- 选择的牌或“跳过”；
- 每题响应时间和提交时间。

页面不收集姓名、手机号、微信号、精确位置或设备标识。不要将参与者的私密聊天、联系方式或其他个人信息写入提交结果。

## 题池

`tasks.json` 包含 800 道由规则引擎生成的真实局面选择题，来自 51 局。静态页会选一整局并按手数排序展示。题池不应包含对手隐藏手牌。

重新生成题池、自动接收提交和审计数据需要完整训练项目中的生成器与服务端，不在此静态仓库中。

## 牌面来源

万、条、筒牌面照片来自 MIT 许可的 `Camerash/mahjong-dataset` 中国麻将牌数据集。项目只保留川麻使用的 27 种花色牌，并移除了数据集附带的红色角标。来源和许可证见 `tiles_cn/SOURCE.md` 与 `tiles_cn/LICENSE-dataset.md`。

## 部署

仓库包含 GitHub Pages 工作流。进入仓库的 **Settings → Pages**，将 **Source** 设置为 **GitHub Actions**。推送到 `main` 后，工作流会发布当前静态页面。
